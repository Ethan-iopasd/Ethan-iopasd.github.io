三 异步编程 asyncio 本篇

开场：asyncio 只解决「等待」，不解决「计算」

I/O 密集 → 用 asyncio 有明显收益。CPU 密集 → 用多进程，asyncio 帮不上忙，甚至更慢。

记住这条，能避免大部分误用。

一、协程、事件循环、任务

概念 是什么
协程（coroutine） async def 定义的函数，调用它返回协程对象，不会执行
事件循环（event loop） 调度器，决定哪个协程在什么时候跑
任务（Task） 把协程包装成「被事件循环调度的单位」
await 把控制权交还事件循环，等这个协程就绪再回来

⚠️ fetch() 不加 await 只是创建了一个协程对象，不会执行，还会抛
RuntimeWarning: coroutine was never awaited。这是最常见的错误。

二、并发执行：gather vs 逐个 await

这是 asyncio 最大的收益点 —— 把「等 A 完再等 B」变成「同时等 A、B、C」。

gather 的几个参数

参数 作用
return_exceptions=True 单个任务抛错不中断其他，异常作为结果返回
return_exceptions=False（默认） 任一任务抛错，gather 立即抛错，其他任务不会被取消

⚠️ 默认行为下，一个任务失败，其他任务仍在后台跑（不会被取消），可能造成资源泄漏。
需要「一失败就全停」用 TaskGroup（3.11+）。

TaskGroup（3.11+）

**新代码优先用 TaskGroup**，语义更清晰，异常处理更安全。

其他组合方式

函数 行为
asyncio.gather 全部完成，返回结果列表（保持顺序）
asyncio.TaskGroup 全部完成，一失败取消其余（3.11+）
asyncio.as_completed 谁先完成先返回
asyncio.wait 按条件等（FIRST_COMPLETED 等），返回 (done, pending)
asyncio.wait_for 加超时

三、asyncio.sleep 不能换成 time.sleep

⚠️ 任何同步阻塞调用都会卡住整个事件循环：requests.get()、time.sleep()、
大量 CPU 计算、同步文件 I/O。

阻塞调用的三种处理方式

场景 方案
有异步库 直接用异步库（httpx、asyncpg、aiofiles）
只有同步 I/O 库 asyncio.to_thread
CPU 密集 ProcessPoolExecutor
拿不准 先看是不是真的阻塞了事件循环

四、同步与异步不能混用

在异步函数里调同步函数 —— 直接调，但会阻塞

在同步函数里调异步函数 —— 不能直接 await

这是设计使然：异步函数必须由事件循环驱动，同步调用栈里没有循环。

常见框架里的表现

框架 注意点
FastAPI 路由函数可以是 async def 或普通 def；普通 def 会被丢进线程池，不会阻塞
Django（ASGI） 视图用 async def，但 ORM 在 4.1+ 才支持异步接口
Flask 本身是 WSGI，不原生支持 async

⚠️ FastAPI 里把同步阻塞函数写成 async def 是最常见的事故：
写成 async def 却在里面调 requests.get()，会把整个事件循环卡住，
所有并发请求一起变慢。要么用异步库，要么写成普通 def。

五、取消与超时

⚠️ CancelledError 不要静默吞掉。 吞掉会让上层以为任务正常结束，导致 gather /
TaskGroup 的取消逻辑失效。要清理就清理，然后 raise。

超时的三种写法

六、asyncio.run 只能调一次

正确做法：把需要并发的任务都放进同一个 main() 里。

七、调试技巧

事件循环卡住时，先怀疑某个同步阻塞调用，其次怀疑死循环里没有 await。

常见坑清单

  • 调用协程函数忘了 await（只创建了协程对象）
  • 在协程里用 time.sleep() / requests.get() 阻塞事件循环
  • 把 CPU 密集计算放进 async def（应该用进程池）
  • FastAPI 里写 async def 却调同步阻塞库，拖垮所有并发请求
  • 逐个 await 本该并发的请求，白白串行
  • gather 没设 return_exceptions，一个失败后其他任务仍在跑
  • 吞掉 CancelledError，破坏取消语义
  • 反复调用 asyncio.run()，无法复用连接池
  • 忘了设超时，一个慢请求拖住整批任务
  • 在模块顶层用 asyncio.run() 启动服务（应该放 if __name__ == "__main__"）
  • 用 asyncio.create_task() 创建任务但不保存引用，可能被 GC 回收
