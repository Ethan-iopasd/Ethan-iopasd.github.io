六 位运算与数学技巧 本篇

开场：一句话结论

位运算考点只有两类 —— 把整数当 32/64 位集合用，和用补码性质做 O(1) 技巧；数学题失分点几乎全在溢出、负数取模、精度三处。

一、位运算基础

运算 符号 语义
与 / 或 / 异或 a & b · a | b · a ^ b 都为 1 / 有一个 1 / 不同为 1
取反 ~a 按位取反（含符号位）
左移 a << k 低位补 0，等价 a * 2^k
算术右移 a >> k 高位补符号位
逻辑右移 a >>> k 高位补 0

负数用补码表示：~x = -x - 1，-x = ~x + 1。5 = 0000 0101，~5 = 1111 1010 = -6。

右移差异（最易写错）：

语言 算术右移 逻辑右移
Java / JavaScript >> >>>
C / C++ / Go >>（有符号为算术） 转 unsigned / uint 再 >>
Python >>（大整数，无限符号扩展） 需先 & mask 模拟

⚠️ C / C++ / Java / JS 里位运算优先级低于比较运算符：n & 1 == 0 解析成 n & (1 == 0)。C 中 1 == 0 是 0，条件恒假且不报错。
⚠️ Go 是例外：& / << / >> 优先级高于 ==，n&1 == 0 就是 (n&1) == 0。跨语言一律加括号。

二、常用位技巧

Brian Kernighan 数 1：每轮清一个最低位 1，循环次数 = 1 的个数。

复杂度：逐位检查 O(位数)，Brian Kernighan O(1 的个数)，内建函数 O(1)。内建实现：

语言 写法
Python 3.10+ / < 3.10 n.bit_count() / bin(n).count('1')
Java Integer.bitCount(n) / Long.bitCount(n)
Go math/bits.OnesCount32/64
C / C++ __builtin_popcount(ll)
Rust n.count_ones()

⚠️ **判 2 的幂必须确认 n > 0**：0 & -1 == 0 恒成立，会把 0 误判。写成 n > 0 and (n & (n-1)) == 0。
⚠️ n & -n 依赖定长补码。Python 大整数符号无限扩展，负数结果与 32 位不同，位题里先按位宽 mask 归一。

三、异或的性质

不用临时变量交换（仅作知识）：a ^= b; b ^= a; a ^= b。

⚠️ 工程上不要用异或交换：若 a、b 是同一变量或同一内存别名，三步后结果归 0，静默出错。t=a;a=b;b=t 编译器优化已足够。
⚠️ 异或不满足幂等（a ^ a ^ a = a），做「异或前缀和」别套加法直觉。

五、溢出与边界

场景 问题 处理
int 溢出 超过 2^31-1 回绕成负 提前转 long
-MIN_VALUE 结果仍是 MIN_VALUE 用 long 接收
Math.abs(MIN_VALUE) 返回仍是负数 先转 long
大数相乘 两 int 先溢出再赋值 (long) a * b
有 / 无符号混用 隐式转无符号，负数变大正数 显式转型

⚠️ Math.abs(Integer.MIN_VALUE) 无效 —— JDK 明确记录，返回值仍为负，取绝对值前先升 long。
⚠️ 转 long 转晚了没用：a * b > c 里 a * b 已按 int 溢出。
⚠️ C / C++ 有符号与无符号混用会隐式转无符号，-1 < 10u 为假；开 -Wsign-compare 能抓大部分。

六、数学技巧

快速幂 / 矩阵快速幂：O(log b)，模版边乘边取模防溢出，矩阵版用来加速线性递推（斐波那契等）。

gcd / lcm / 扩展欧几里得：

⚠️ lcm 必须先除后乘。a * b // gcd 在接近 int 上限时乘法先溢出。
⚠️ **gcd(0, 0) == 0**，Python / Java BigInteger 的 gcd 对负数返回非负。

素数筛：

算法 复杂度 特点
试除法 O(√n) 单次 判单个数
埃氏筛 O(n log log n) 简单，会重复标记
线性筛 O(n) 每合数只被最小质因子标记一次

⚠️ **埃氏筛内层从 i * i 起，不是 2 * i**；线性筛的 i % p == 0 必须 break，否则退化。

模运算：

语言 -7 % 3 规则
C / C++ / Java / Go / JS -1 向零截断
Python 2 向下取整（符号跟除数）

⚠️ 移植模运算必踩：C / Java -1 % 3 == -1，Python == 2。需非负结果统一写 ((a % m) + m) % m。
⚠️ pow(a, b, m) 是 Python 内建函数（大指数取模），math.pow 是浮点版且不支持三参数。

组合数与卡特兰数：comb(5, 2) == 10（Python 3.8+）；卡特兰数 C(2n,n)/(n+1) 用于合法括号、出栈序列、二叉树形态数。

几何：叉积 cross(o,a,b) = (a-o)×(b-o)，>0 逆时针、=0 共线；多边形面积用鞋带公式。

⚠️ 叉积是有向面积，cross(o,a,b) 与 cross(o,b,a) 符号相反，参数顺序别写反。
⚠️ 几何题用整数叉积比较，不要提前转浮点；== 0 判共线只在整数坐标下可靠。

randN 实现 randM（拒绝采样）：用 rand5()*5 + rand5() 均匀产生 0..24，取 < 21 的再 % 7。

精度：abs(a - b) < EPS 比较浮点；sqrt(x+1) - sqrt(x) 直接算丢精度，改写成 1 / (sqrt(x+1) + sqrt(x))。

⚠️ sort(() => Math.random() - 0.5) 不是均匀洗牌，依赖排序比较次数与顺序，不同引擎分布不同且必然有偏。
⚠️ Fisher-Yates 的 j 必须取自 [0, i]（含 i），写成 [0, i-1] 会破坏均匀性。
⚠️ rand5() + rand5() 不是均匀分布（中间值概率高），要用进制展开 rand5()*5 + rand5()。
⚠️ 浮点数不要用 ==，用 epsilon；量级差异大时要用相对误差；相近大数相减会灾难性抵消，能改写就先改写。

常见坑清单

  • n & 1 == 0 不加括号（C / Java / JS 解析成 n & (1==0)）
  • 以为 Go 的位运算优先级和 C 一样（Go 里 & 高于 ==）
  • 判 2 的幂不检查 n > 0，把 0 误判
  • 对负数做 n & -n，未先按位宽归一化
  • 用异或交换变量，遇到别名时结果归零
  • 子集枚举漏掉空集，或把 (s-1) & mask 写成 s-1
  • 1 << k 在 32 位下 k ≥ 32，未定义行为或按模取位移
  • Math.abs(Integer.MIN_VALUE) 返回负数
  • 两个 int 相乘后才转 long，已经溢出
  • C 里有符号与无符号混用比较，负数被当成大正数
  • lcm 写成 a * b // gcd，先乘后除溢出
  • 跨语言搬模运算，忘了负数取模符号不同
  • 用 math.pow 做三参数取模（应用内建 pow）
  • 埃氏筛从 2 * i 而非 i * i 开始
  • 线性筛忘记 i % p == 0 时 break
  • 用 sort(() => Math.random() - 0.5) 洗牌
  • Fisher-Yates 的随机下标取错区间
  • randN + randN 当均匀分布用
  • 浮点数用 == 比较，或忽略灾难性抵消
  • 几何题提前转浮点再用 == 判共线
